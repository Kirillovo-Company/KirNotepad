1. Базовая структура плагина

Каждый плагин должен быть Python-файлом (.py), помещенным в папку plugins/. Обязательная точка входа — это функция setup(), которая принимает словарь контекста в качестве единственного аргумента.
Python

# new_plugin_name.py
from tkinter import messagebox

# Глобальный словарь для хранения данных плагина
PLUGIN_CONTEXT_DATA = {}

def setup(context_data):
    """
    Точка входа плагина.
    context_data: Словарь, содержащий все функции и виджеты редактора.
    """
    global PLUGIN_CONTEXT_DATA
    
    if context_data is None:
        return
        
    # Всегда сохраняйте контекст для использования в других функциях плагина
    PLUGIN_CONTEXT_DATA = context_data 
    
    # Регистрация действий:
    # 1. Добавление пункта в меню:
    menu = PLUGIN_CONTEXT_DATA['menu']
    menu.add_command(label='Наше новое действие', command=run_action)
    
    # 2. Привязка горячей клавиши (например, Ctrl+Shift+A):
    root_widget = PLUGIN_CONTEXT_DATA['root']
    root_widget.bind('<Control-Shift-a>', lambda e: run_action())

    print("Плагин успешно загружен и готов к работе.")


def run_action():
    """Функция, которая выполняет основное действие плагина."""
    
    # Получаем текущий текст
    text = PLUGIN_CONTEXT_DATA['get_content']() 
    
    # Вставляем что-то в редактор
    PLUGIN_CONTEXT_DATA['insert_text']('// Действие выполнено! //')
    
    # Обновляем подсветку
    PLUGIN_CONTEXT_DATA['changes_notifier']()
    
    PLUGIN_CONTEXT_DATA['messagebox'].showinfo('Плагин', f'Обработано {len(text)} символов.')

2. API Контекст (context_data)

Словарь context_data содержит ссылки на основные виджеты, функции редактора, а также вспомогательные методы.

A. Ссылки на виджеты (Tkinter)

Ключ	Тип	Описание
'root'	tkinter.Tk	Главное окно приложения. Используется для привязки глобальных горячих клавиш (.bind()).
'editor'	tkinter.Text	Виджет текстового редактора. Используется для прямого доступа к функциям Text (например, .tag_add()).
'menu'	tkinter.Menu	Скрытый объект меню плагинов. Используется для регистрации новых пунктов меню: menu.add_command(...).
'messagebox'	tkinter.messagebox	Модуль для вывода диалоговых окон (.showinfo(), .showerror()).

B. Функции для работы с контентом

Эти функции — основной способ взаимодействия с текстом в редакторе.
Ключ	Тип	Описание
'get_content'	function	Получает весь текст из редактора. Возвращает строку.
'set_content'	function	Заменяет весь текст в редакторе. Принимает аргумент content: str.
'insert_text'	function	Вставляет текст в позицию курсора (INSERT). Принимает аргумент text: str.
'changes_notifier'	function	Запускает механизм подсветки синтаксиса и обновляет статус "Сохранено". Обязательно вызывайте после любых программных изменений текста!
'current_file'	function	Возвращает полный путь к текущему открытому файлу (строка) или None, если файл новый.

C. Функции для работы со стилями и настройками

Ключ	Тип	Описание
'get_color'	function	Возвращает HEX-код цвета из config.json по его имени (например, 'background'). Принимает аргумент color_name: str.
'get_font'	function	Возвращает строку шрифта из config.json (например, 'Consolas 15').

3. Рекомендации по разработке

    Используйте changes_notifier(): После любого изменения текста, вставленного программно (например, через 'insert_text' или 'set_content'), обязательно вызывайте PLUGIN_CONTEXT_DATA['changes_notifier']() для обновления подсветки и статуса сохранения.

    Использование виджетов Tkinter: Если вы создаете собственные виджеты (как IDE Sidebar), всегда используйте PLUGIN_CONTEXT_DATA['root'] в качестве родительского элемента или используйте фреймы, упакованные внутри root.

    Безопасность: Помните, что exec(code, ...) в функции run_code() плагина IDE потенциально небезопасен, поскольку он выполняет код в контексте вашего приложения. Используйте его только для тестирования или в контролируемой среде.
