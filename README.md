## KirNotepad — продвинутый текстовый редактор с поддержкой плагинов
KirNotepad — это простой, но мощный текстовый редактор с графическим интерфейсом, написанный на Python с использованием библиотеки tkinter. Он ориентирован на гибкость, настраиваемость и расширяемость через плагины, а также поддерживает синтаксическую подсветку для нескольких языков и настраиваемые горячие клавиши.

## 🔧 Основные возможности


## Работа с файлами:

Создание новых файлов (Ctrl+N).
Открытие существующих (Ctrl+O).
Сохранение (Ctrl+S) — с поддержкой выбора пути при первом сохранении.
Автоматическое определение типа файла по расширению.

## Синтаксическая подсветка:

Поддержка языков: Python, HTML, CSS, JS, C/Java/PHP/Ruby и др.
Цвета настраиваются через config.json.
Подсветка работает в реальном времени при вводе текста.

## Гибкая настройка через JSON:

Конфигурация хранится в config.json.
Можно задавать:

Цвета интерфейса (RGB-формат).
Шрифт (например, Consolas 15).
Горячие клавиши.
При запуске автоматически создаётся стандартная конфигурация, если файл отсутствует или повреждён.

## Плагины (Plugin System):

Плагины хранятся в папке plugins/.
Каждый .py-файл (не начинающийся с _) считается плагином.
Плагины получают доступ к редактору через контекст (plugin_context), включающий:

editor, root, get_content, set_content, insert_text, messagebox, menu и т.д.
Для подключения плагина требуется функция setup(context).

## Горячие клавиши (настраиваемые):

Ctrl+S — сохранить.
Ctrl+O — открыть.
Ctrl+N — новый файл.
Ctrl+Q — о программе.

## 🎨 Интерфейс и стиль

Тёмная тема по умолчанию (настраиваемый фон #2a2a2a).
Шрифт задаётся в конфиге.
Прокрутка с помощью Scrollbar.
Автоматическая перезагрузка конфигурации при запуске.
Безопасное освобождение ресурсов при закрытии окна.

## ✅ Преимущества

Лёгкий и не требует внешних зависимостей.
Прост в расширении.
Подходит как для обучения, так и для использования как базы под собственный IDE.

## ❌ Ограничения

Подсветка синтаксиса использует регулярные выражения, что не всегда надёжно (особенно для вложенных строк или комментариев).
Нет автозавершения, подсказок или отладки.
Нет вкладок (один файл за раз).

## 🚀 Как запустить
python 1.4/kn1.4.py
Убедитесь, что установлен Python 3.6+.
